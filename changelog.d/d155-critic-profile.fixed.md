The critic profile can now be configured: `profiles.<client>.critic` is accepted (it was refused as an unknown class), and the configuration page proposes the `normal` profile when the critic row is turned on and shows readable values in the review (`Off` / `On (model: ..., effort: ..., maxTurns: ...)`) instead of `false` / `Default`. The smoke demo preview now refuses at once when the client has no critic profile, saying which profile is missing and how to set it. The confirmation code of the preview no longer changes when the allowance reading is only renewed (its age and timestamps are out of the code); it changes when the work, the helper, a ceiling, the floor or the allowance band changes. / O perfil de crítico agora pode ser configurado: `profiles.<cliente>.critic` é aceito (era recusado como classe desconhecida), e a tela de configuração propõe o perfil `normal` quando a linha do crítico é ligada e mostra valores legíveis na revisão (`Desligado` / `Ativo (model: ..., effort: ..., maxTurns: ...)`) em vez de `false` / `Padrão`. A prévia da demonstração agora recusa na hora quando o cliente não tem perfil de crítico, dizendo qual perfil falta e como configurá-lo. O código de confirmação da prévia não muda mais quando a leitura de cota é apenas renovada (a idade e os horários ficam fora do código); ele muda quando o trabalho, o ajudante, um teto, o piso ou a faixa da cota muda.
