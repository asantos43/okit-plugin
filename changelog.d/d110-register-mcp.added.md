The installer now registers the MCP server of the plugin in the client it installs, through the client's own `mcp` commands: the entry named `okit` is read first, added when it is absent, taken out and written again when it still points at the version the installation replaces, and kept (with a warning) when it is not ours. The entry is ours only when it is a stdio server whose own arguments field names our path, whole. An entry the client cannot read is a warning, not an absent entry: nothing is written, and the next install of the same version tries again. The uninstall takes our entry out before the plugin it points at is removed, and a client that refuses the entry is a warning, not a failed installation. Claude Code and Codex are registered; OpenCode is not registered by the installer yet. In Codex, whose `mcp get` does not say where an entry is kept, the entry is only added when it is missing: an entry that is already there is never replaced nor removed by the installer, and the warning prints the commands to run by hand. / O instalador agora registra o servidor MCP do plugin no cliente em que instala, pelos comandos `mcp` do próprio cliente: a entrada chamada `okit` é lida primeiro, adicionada quando está ausente, tirada e escrita de novo quando ainda aponta para a versão que a instalação substitui, e mantida (com um aviso) quando não é nossa. A entrada é nossa só quando é um servidor stdio cujos próprios argumentos nomeiam o nosso caminho, inteiro. Uma entrada que o cliente não consegue ler é um aviso, não uma entrada ausente: nada é escrito, e a próxima instalação da mesma versão tenta de novo. A desinstalação tira a nossa entrada antes de remover o plugin para onde ela aponta, e um cliente que recusa a entrada é um aviso, não uma instalação falha. O Claude Code e o Codex são registrados; o OpenCode ainda não é registrado pelo instalador. No Codex, cujo `mcp get` não diz onde a entrada fica, a entrada só é adicionada quando falta: uma entrada que já está lá nunca é trocada nem removida pelo instalador, e o aviso mostra os comandos para rodar à mão.
