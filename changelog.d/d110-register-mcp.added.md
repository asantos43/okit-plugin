The installer now registers the MCP server of the plugin in the client it installs, through the client's own `mcp` commands: the entry named `okit` is read first, added when it is absent, taken out and written again when it still points at the version the installation replaces, and kept (with a warning) when it is not ours. The uninstall takes our entry out before the plugin it points at is removed, and a client that refuses the entry is a warning, not a failed installation. / O instalador agora registra o servidor MCP do plugin no cliente em que instala, pelos comandos `mcp` do próprio cliente: a entrada chamada `okit` é lida primeiro, adicionada quando está ausente, tirada e escrita de novo quando ainda aponta para a versão que a instalação substitui, e mantida (com um aviso) quando não é nossa. A desinstalação tira a nossa entrada antes de remover o plugin para onde ela aponta, e um cliente que recusa a entrada é um aviso, não uma instalação falha.
