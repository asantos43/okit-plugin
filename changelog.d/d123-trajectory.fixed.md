Saving a session that already has a file merges the two runs under the lock instead of replacing the file: every step of both runs is kept and the richer step wins the position they share, so a smaller or concurrent save never shrinks the file / Gravar uma sessão que já tem arquivo mescla as duas execuções sob a trava em vez de substituir o arquivo: todos os passos das duas execuções são mantidos e o passo mais rico vence a posição compartilhada, então uma gravação menor ou concorrente nunca encolhe o arquivo
A corrupt saved file is renamed aside (`<file>.corrupt-<timestamp>`) instead of being merged, and the new save still goes through / Um arquivo salvo corrompido é renomeado para o lado (`<arquivo>.corrupt-<carimbo>`) em vez de ser mesclado, e a nova gravação continua passando
Two concurrent saves of the same session end with the union of both runs, never with the last writer alone / Duas gravações concorrentes da mesma sessão terminam com a união das duas execuções, nunca só com a última
A lock that does not free up within its wait ends in a plain refusal instead of waiting for ever / Uma trava que não se libera dentro da espera termina em recusa clara em palavras simples em vez de esperar para sempre
