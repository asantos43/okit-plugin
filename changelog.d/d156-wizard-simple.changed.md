The install wizard has four plain screens (what to do, confirm, installing, done): the plan is shown as a readable summary per client (the JSON is in a collapsed "View details"), the screen says "Calculating..." with the stage while the plan is computed, the optional steps are a checklist on the done screen, and the header shows only the language selector / O assistente de instalação tem quatro telas simples (o que fazer, confirmar, instalando, pronto): o plano aparece como resumo legível por cliente (o JSON fica em "Ver detalhes", recolhido), a tela diz "Calculando..." com a etapa enquanto o plano é calculado, os passos opcionais são uma lista na tela final e o cabeçalho mostra só o seletor de idioma.
