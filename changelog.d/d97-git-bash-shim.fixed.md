On Windows the status bar collector now works: the installer also writes an extensionless shim for Git Bash (the shell Claude Code runs the status bar command through, which cannot run a `.cmd` by bare name), the status bar entry names the absolute path of that shim (an older entry with the bare command is rewritten on install or update, keeping its `--previous` command), and `okit-plugin status` says when the collector is active but has received no reading yet / No Windows o coletor da barra de status agora funciona: o instalador grava também um atalho sem extensão para o Git Bash (o shell pelo qual o Claude Code roda o comando da barra de status, que não consegue rodar um `.cmd` pelo nome solto), a entrada da barra de status usa o caminho absoluto desse atalho (uma entrada antiga com o comando solto é reescrita na instalação ou atualização, mantendo o comando de `--previous`) e `okit-plugin status` avisa quando o coletor está ativo mas ainda não recebeu nenhuma leitura.
