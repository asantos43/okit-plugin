The installer output is one presenter for `install.sh`, `install.ps1` and `okit-plugin install|update|uninstall`: the same numbered steps on Linux, macOS and Windows, one language per run, the SHA-256 note once, no temporary folder, the next steps with the exact command, and raw commands only with `--verbose` / A saída do instalador passa por um único apresentador no `install.sh`, no `install.ps1` e em `okit-plugin install|update|uninstall`: os mesmos passos numerados no Linux, no macOS e no Windows, um idioma por execução, a nota do SHA-256 uma vez, nenhuma pasta temporária, os próximos passos com o comando exato e os comandos brutos só com `--verbose`.
Unknown flags and invalid configuration JSON use the explicit or environment language even before configuration loading / Flags desconhecidas e JSON de configuração inválido usam o idioma explícito ou do ambiente mesmo antes da leitura da configuração.
Bootstrap scripts also select --locale before validating flags, keeping early refusals in the requested language / Os scripts de bootstrap também escolhem --locale antes de validar flags, mantendo as recusas iniciais no idioma solicitado.
Regression tests reject repeated step completions and their late notes / Testes de regressão rejeitam conclusões repetidas de um passo e suas notas tardias.
Regression tests reject setup offers after failure, dry-run or update --check / Testes de regressão rejeitam ofertas de setup após falha, dry-run ou update --check.
The download refusal (the HTTP status and the text that came with it) is translated into Brazilian Portuguese / A recusa de download (o status HTTP e o texto que veio com ele) fica traduzida para português brasileiro.
The archive refusals, the invalid install configuration and the broken-kit state are also translated into Brazilian Portuguese, and a test covers every refusal in the installer / As recusas de pacote, a configuração de instalação inválida e o estado de kit com defeito também ficam traduzidos para português brasileiro, e um teste cobre toda recusa do instalador.
