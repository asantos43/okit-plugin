When the status bar collector of an account could not be registered, the panel, the account list and the web page said only "Could not register the collector" and the doctor said nothing. Now the reason names the file (the `settings.json` of the account) and what is wrong with it (it does not exist, it is not valid JSON, it has no collector command, or it cannot be written: check permissions), and the doctor has a row "Account collector" for each saved account of Claude Code that says if it is registered and, if not, the reason and what to do (fix the file or its permissions, then run `okit-plugin doctor --fix`). / Quando o coletor da barra de status de uma conta não podia ser registrado, o painel, a lista de contas e a página web diziam só "Não foi possível registrar o coletor" e o doctor não dizia nada. Agora o motivo nomeia o arquivo (o `settings.json` da conta) e o que há de errado com ele (não existe, não é um JSON válido, não tem o comando do coletor ou não pode ser gravado: verifique as permissões), e o doctor tem uma linha "Coletor da conta" para cada conta salva do Claude Code que diz se está registrada e, se não, o motivo e o que fazer (corrija o arquivo ou as permissões e rode `okit-plugin doctor --fix`).
