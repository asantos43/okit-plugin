Every input the installer takes in is now listed in one generated inventory (`test/helpers/input-inventory.js`) and proved by `test/input-inventory.test.js`: the configuration keys read, each number at its exact limit (the maximum passes, one past it is refused), the flags of every command, the `OKIT_*` variables and the files read. A value outside its domain is a refusal of usage (exit 2) in the language of the run; a file that cannot be read is exit 1. Fixed on the way: `limitWarnings` of the wrong type; `xdgEnv` without `xdgParts` and the reverse; HTTP `headers` with values the request cannot send (non-ASCII or line breaks) and an `api` address with a user name or password, refused by the schema instead of failing as a network error; `OKIT_SYSTEMS`, `OKIT_ARCHITECTURES` and the other `OKIT_*` settings of `install.sh` and `install.ps1` that are not valid, refused with exit 2 before `uname` and the network; `telemetry export --since nope`; timeouts of the telemetry above what a timer takes; `--repo ..`; `autostart show --kind` with no value; an installation record of the wrong shape (exit 2) or not JSON (exit 1); a `config.json` whose root is not an object; line breaks in a name typed by the person in pt-BR refusals.
