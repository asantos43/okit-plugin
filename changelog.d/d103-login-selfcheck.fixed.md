The post-install self-check also starts the shell the way a new terminal does (`bash -lc`, `zsh -lc`, `sh -lc`, `fish -l -c`) for the shell whose profile holds the installer's PATH block: a profile that exits early, fails or never reaches the PATH block now fails the install with the shell, the reason and the exact fix, instead of passing / A autoverificação depois da instalação também inicia o shell como um terminal novo o inicia (`bash -lc`, `zsh -lc`, `sh -lc`, `fish -l -c`) para o shell cujo perfil guarda o bloco de PATH do instalador: um perfil que sai cedo, falha ou nunca chega ao bloco de PATH agora faz a instalação falhar, dizendo o shell, o motivo e a correção exata, em vez de passar.
