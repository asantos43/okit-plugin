The core functions now live in one registry (`src/core/operations.js`): each operation has a name, a description in English and Brazilian Portuguese, the schema of its arguments and one handler that returns data and never prints. The command line keeps the argv and the lines it prints and calls the registry for the logic, so the same behaviour and the same output stand; the MCP server will read the same entries in the next step. / As funções do núcleo agora vivem em um registro (`src/core/operations.js`): cada operação tem um nome, uma descrição em inglês e português brasileiro, o esquema dos argumentos e um único executor que devolve dados e nunca imprime. A linha de comando continua com o argv e com as linhas que imprime e chama o registro para a lógica, então o mesmo comportamento e a mesma saída permanecem; o servidor MCP vai ler as mesmas entradas no próximo passo.
The arguments of an operation are checked more strictly: only a plain object is taken, only its own keys are read, an explicit `null` is refused instead of passing for an absent value, a name with a space around it is refused, and the name of a client must be a name and never a path. / Os argumentos de uma operação são verificados com mais rigor: só um objeto simples é aceito, só as chaves próprias são lidas, um `null` explícito é recusado em vez de passar por valor ausente, um nome com espaço ao redor é recusado, e o nome de um cliente tem de ser um nome e nunca um caminho.
The checks are stricter still: an argument the operation does not take is refused even when it hides (a symbol or a property that is not enumerable), a configured client whose name is not a name is never listed, read nor written, and a daemon that is asked for a table without the table dependencies of the caller refuses instead of answering with no table. / As verificações ficaram mais rigorosas ainda: um argumento que a operação não aceita é recusado mesmo quando se esconde (um símbolo ou uma propriedade que não é enumerável), um cliente configurado cujo nome não é um nome nunca é listado, lido nem gravado, e um daemon pedido com a tabela sem as dependências da tabela de quem chama recusa em vez de responder sem a tabela.
