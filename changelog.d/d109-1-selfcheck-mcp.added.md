The self-check after an install now proves the MCP server of the installation: a small probe starts the server under a temporary state root (your own state is never touched) and asks it to answer, and then asks its control API one tool call; each answer is a row of its own, and a server that does not answer fails the run with the command to run again / A autoverificação depois de uma instalação agora prova o servidor MCP da instalação: uma pequena sonda inicia o servidor sob uma raiz de estado temporária (o seu estado nunca é tocado) e pergunta se ele responde, e depois pergunta à API de controle dele uma chamada de ferramenta; cada resposta é uma linha própria, e um servidor que não responde faz a execução falhar com o comando para rodar de novo.
