`okit-plugin install` and `uninstall` accept `--client claude-code|codex --account <id>` to register or unregister the plugin (plugin entry, MCP entry, hooks, status bar) in that account's folder only, and `update` registers the new version in every registered account; the files of the plugin stay shared and are removed with the last registration / `okit-plugin install` e `uninstall` aceitam `--client claude-code|codex --account <id>` para registrar ou cancelar o registro do plugin (entrada do plugin, entrada MCP, hooks, barra de status) somente na pasta dessa conta, e o `update` registra a nova versão em todas as contas registradas; os arquivos do plugin continuam compartilhados e saem com o último registro.
