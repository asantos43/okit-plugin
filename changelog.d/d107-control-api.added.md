The MCP server now opens a local control API (a private socket on Linux and macOS, a named pipe on Windows) that runs a tool for another program of the same user with the same text MCP returns; every call carries a random token, frames over 1 MiB, a ninth connection and idle connections are refused, and if the endpoint cannot be created the MCP server keeps working. / O servidor MCP agora abre uma API de controle local (socket privado no Linux e no macOS, pipe nomeado no Windows) que executa uma ferramenta para outro programa do mesmo usuário com o mesmo texto do MCP; toda chamada leva um token aleatório, quadros acima de 1 MiB, uma nona conexão e conexões ociosas são recusados, e se o ponto de acesso não puder ser criado o servidor MCP continua funcionando.
