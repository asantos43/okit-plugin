# Contributing

Thanks for your interest. This project is in design phase (pre-alpha).

## How to contribute

- Contributions arrive as pull requests only. Open an issue first if you want to
  discuss a change.
- `main` is protected: pull requests must go through review, and no one pushes
  directly to it.
- Keep pull requests small: one topic per pull request.
- Every change must come with tests. Run `npm test` before you open it.

## Language

- Code, identifiers, commit messages and code comments in English.
- User documentation in English and pt-BR: when you change behaviour, update
  `README.md` and `README.pt-BR.md`, plus `docs/DESIGN.md` and
  `docs/DESIGN.pt-BR.md` when the design changes.

## Changelog

Add one line under `[Unreleased]` in `CHANGELOG.md` describing your change.
