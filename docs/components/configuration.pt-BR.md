# Configuração

![okit-plugin: Componentes](../images/banners/components.svg)

`language` escolhe o idioma dos comandos e ferramentas MCP: padrão `en`, também aceita `pt-BR`. Configure português uma vez com `okit-plugin config set language pt-BR`; `okit-plugin config unset language` restaura inglês. Um `--locale` ou `locale` no MCP informado na chamada tem prioridade. Idiomas não aceitos são recusados com uma mensagem nos dois idiomas.

A configuração combina padrões internos e escolhas salvas na raiz de estado. Instalar/atualizar preenche apenas campos ausentes de perfis ativos e limites por cliente. Escolhas existentes, inclusive perfis desligados, são mantidas. `setup.detected.client` registra o cliente em uso; `setup.detected.quotaSources` registra fontes de cota observadas. Observações desconhecidas são omitidas. A detecção reutiliza os leitores existentes sem gastar cota nem confirmar a configuração.

<a id="read"></a>
## Consultar e alterar

Use `okit-plugin config show`, `okit-plugin config get limits.global`, `okit-plugin config set limits.global 3` e `okit-plugin config unset limits.global`. A CLI valida só as chaves do esquema abaixo; demais opções técnicas são sobrescritas no config.json, não aceitas por config set. Perfis e detecção mesclam por cliente/classe/campo; outros consumidores podem mesclar grupos com regras próprias. Faça backup antes de editar.

## Chaves aceitas pela CLI

client é um cliente configurado; class é simple, normal ou hard. O padrão de cada campo está no inventário. Sem override de limits.clients, vale limits.global; profiles.<client>.<class> aceita somente null para desativar. limits.perClient é alias legado de limits.global.

## Opções sem padrão no objeto central

O código também lê `daemon.intervalSeconds` = 60, `daemon.logKeepDays` = 14, `daemon.maxTurns`/`daemon.maxMinutes` = ausentes ([daemon](../../src/daemon.js)); `orders.retentionDays` = 90 ([orders](../../src/orders.js)); `configuredClients` = nomes das entradas de perfis salvas ([profiles](../../src/profiles.js)); `setup.done.at` = ausente até confirmação do setup ([setup](../../src/setup/setup.js)). Intervalo controla o loop; retenções controlam remoção de logs/ordens; máximos limitam execução; configuredClients delimita clientes configurados; setup.done registra conclusão, sem comprovar acesso à conta. Nomes de modelos padrão são candidatos, não comprovação de acesso. Cota desconhecida/vencida bloqueia a política de início do ambiente, separada da verificação do daemon.

Medições: `telemetry.enabled` false, `telemetry.destination` file, `telemetry.dir` telemetry, `telemetry.retentionDays` 7, `telemetry.maxBytes` 10485760, `telemetry.maxFileBytes` 1048576, `telemetry.batchSeconds` 60 (reservado), `telemetry.kitExecutable` kit, `telemetry.kitConfigFile` null, `telemetry.kitTimeoutMs` 1000; `telemetry.rede.ligado` false, `telemetry.rede.endpoint` null, `telemetry.rede.cabecalhos` {}, `telemetry.rede.timeoutMs` 5000. Gravação local e envio exigem escolhas separadas; kit fornece somente destino/retenção. Gravações: `trajectory.enabled` false; `trajectory.dir` trajectory; `trajectory.retentionDays` 7; `trajectory.maxBytes` 10485760; `trajectory.maxFileBytes` 1048576; `trajectory.truncationMarker` aviso bilíngue de redução; `trajectory.redactionMarker` aviso bilíngue de ocultação; `trajectory.redactionPatterns` expressões regulares sem distinção de maiúsculas para segredos, tokens, credenciais bearer e chaves privadas. Sobrescreva no config.json; on/off permite escolher a gravação. Limites devem ser inteiros positivos; limites menores que os metadados obrigatórios impedem salvar. Veja [gravações](state.pt-BR.md#trajectories). [Visão geral](README.pt-BR.md) · [Estado](state.pt-BR.md) · [English](configuration.md)
