# User guide

![okit-plugin: User guide](../images/banners/guide.svg)

Choose a task to get the plugin working and ask your assistant for help.

<a id="tasks"></a>
## Choose a task

1. [Install and start](install.md): download the installer, then check the environment report.
2. [Choose models and record allowance](models-and-quota.md): save choices and inspect what is available.
3. [Ask the Director](ask-the-director.md): describe a result and follow the work.
4. [Preview a demonstration](smoke-demo.md): see the proposed work before approving anything.
5. [Update or remove](update-and-remove.md): review changes before applying them.
6. [Solve a problem](troubleshooting.md): find the repair instruction for a missing item.
7. [Manage accounts](accounts.md): add a separate client folder, log in manually and keep quota per account.
8. [Claude Code panel](panel.md): install the optional pane and read the accounts and work board.
9. [Configuration page](config-ui.md): edit settings and actors in your browser.
