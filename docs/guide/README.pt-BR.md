# Guia do usuário

Escolha uma tarefa para colocar o plugin em funcionamento e pedir ajuda ao assistente.

<a id="tasks"></a>
## Escolha uma tarefa

1. [Instalar e começar](install.pt-BR.md): baixe o instalador e confira o relatório do ambiente.
2. [Escolher modelos e registrar cota](models-and-quota.pt-BR.md): salve escolhas e veja o que está disponível.
3. [Pedir ao Diretor](ask-the-director.pt-BR.md): descreva um resultado e acompanhe o trabalho.
4. [Ver uma demonstração](smoke-demo.pt-BR.md): confira o trabalho proposto antes de aprovar qualquer coisa.
5. [Atualizar ou remover](update-and-remove.pt-BR.md): confira as mudanças antes de aplicá-las.
6. [Resolver um problema](troubleshooting.pt-BR.md): encontre a instrução para corrigir um item ausente.
