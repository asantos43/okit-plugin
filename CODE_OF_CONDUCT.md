# Code of Conduct

We want this project to be a respectful place for everyone.

- Be kind and courteous. Assume good faith.
- Disagree with ideas, not with people.
- No harassment, insults, personal attacks or sexualised language.
- No publishing other people's private information.

## Scope

This applies in repository issues, pull requests, discussions and any other
space related to the project.

## Reporting

If you see unacceptable behaviour, report it to the maintainers through a
private GitHub security advisory, or through the repository owner's profile on
GitHub. Reports are handled privately.
